# 食物消化速度

這是一個可直接部署到 GitHub Pages 的純前端互動教學網站。玩家可同時選擇多種食物，設定份量與咀嚼程度，再利用時間軸觀察不同食物在口腔、食道、胃、小腸、大腸與直腸中的位置與狀態。

## 功能

- 多選食物：水、酒精飲料、一般飲料、米飯、牛排、蔬菜、珍珠、珍珠奶茶、油炸食物等
- 預設餐點：液體與固體比較、一般餐點、點心組合
- 份量與咀嚼程度設定
- 0～72 小時消化時間軸
- 播放、暫停、0.5×～60× 倍速與階段跳轉；1× 每實際 1 秒前進約 2 個模擬分鐘，0.5× 每秒前進約 1 個模擬分鐘
- 前 1 小時提供每 5 分鐘一個時間節點，方便觀察口腔、食道到胃的早期移動
- 每種食物獨立移動
- 食物圖示會隨消化進度縮小，方便辨識目前器官
- 食物依照各自的估計時間前進；若 72 小時仍未完成，會停留在目前器官並以半透明圖示與警告標示
- 顯示目前器官、食物狀態、消化程度與吸收比例
- 時間軸下方以列表顯示目前餐點的每一種食物，可點選切換觀察對象
- 依目前選取食物隨機產生 3～10 題生活情境挑戰題；一次只顯示一題，回答後會鎖定選項並顯示解析，再進入下一題
- 完成挑戰後顯示答對與答錯題數，題庫包含 220 題（每種食物 20 題）
- 「觀察重點」會依目前選擇的食物組合更新
- 響應式設計，支援電腦、平板與手機

## 預設餐點

在左側「一鍵載入預設餐點」區域選擇範例餐點，系統會自動勾選食物並開始模擬。套用後仍可手動勾選或取消食物，再按「把食物放入消化道」重新計算。

預設餐點是課堂示範用的組合，不代表固定或完整的實際飲食建議。

## 消化時間與未完成警告

1× 播放速度每實際 1 秒前進約 2 個模擬分鐘，0.5× 會以每秒約 1 個模擬分鐘播放；時間軸仍可用 1 分鐘為單位拖曳，前 1 小時另提供每 5 分鐘節點。若食物的估計時間超過 72 小時，時間軸到達終點後會保留它在當下器官，並顯示半透明圖示與警告。已在 72 小時內完成的食物則會進入「已排出體外」。

## 挑戰題

載入餐點後，系統會依選取的食物種類與數量從 220 題生活情境題庫中隨機抽題。每次至少 3 題，最多 10 題；重新載入餐點會重新抽取。每題回答後會停用所有選項，顯示完整的正確或錯誤說明，按「下一題」才能繼續，最後會公布答對與答錯數量。題目是課堂用的簡化模型，答案與解析不代表醫療建議。

## 本機執行

直接用瀏覽器開啟 `index.html`，或使用簡易伺服器：

```bash
python3 -m http.server 8000
```

再開啟：

```text
http://localhost:8000
```

## 部署到 GitHub Pages

1. 建立新的 GitHub Repository。
2. 將本專案所有檔案上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. 在 `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/root`。
6. 儲存後等待 GitHub Pages 產生網址。

## 科學說明

本網站中的時間與消化比例為教學用簡化模型。真實人體消化速度會受到個人體質、食物份量、脂肪含量、咀嚼程度、健康狀況與其他因素影響，不應用於醫療診斷。

本網站不再為了讓所有食物在 72 小時內排出而壓縮胃部之後的時間。不同食物、份量與咀嚼程度可能造成估計時間超過時間軸；此時畫面會保留未完成狀態，方便觀察模型的限制。

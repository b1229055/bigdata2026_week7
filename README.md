# 食物消化速度

這是一個可直接部署到 GitHub Pages 的純前端互動教學網站。玩家可同時選擇多種食物，設定份量與咀嚼程度，再利用時間軸觀察不同食物在口腔、食道、胃、小腸、大腸與直腸中的位置與狀態。

## 功能

- 多選食物：水、酒精飲料、一般飲料、米飯、牛排、蔬菜、珍珠、珍珠奶茶、油炸食物等
- 預設餐點：液體與固體比較、一般餐點、點心組合
- 份量與咀嚼程度設定
- 0～72 小時消化時間軸
- 播放、暫停、0.5×～60× 倍速與階段跳轉
- 可切換「全程固定」與「分段流速」兩種模式；全程固定的 1× 每秒前進約 2 個模擬分鐘，分段模式則明確標示前 0～60 分鐘為每秒 1 分鐘、60 分鐘～72 小時為每秒 5 分鐘
- 單一時間軸上提供前 1 小時每 5 分鐘節點，後面接續 6、12、24、48、72 小時標示
- 每種食物獨立移動
- 食物圖示會隨消化進度縮小，方便辨識目前器官
- 食物依照各自的估計時間平順移動；只有時間軸到達 72 小時且仍未完成的食物，才會停留在目前器官並顯示紅色三角形警告與列表標記
- 顯示目前器官、食物狀態、消化程度與吸收比例
- 時間軸下方以列表顯示目前餐點的每一種食物，可點選切換觀察對象
- 依目前選取食物隨機產生 3～10 題生活情境挑戰題；一次只顯示一題，回答後會鎖定選項並顯示解析，再進入下一題
- 完成挑戰後顯示答對與答錯題數，題庫包含 220 題（每種食物 20 題）
- 「觀察重點」會依目前選擇的食物組合更新，並補充對應的消化系統知識
- 挑戰題完成後會解鎖從整個題庫隨機抽出的 1 道食物解謎；`joke-bank.js` 提供 260 道具體食物謎題，不再包含「容易消化」與「難以消化」兩個概括分類
- 觀察重點下方有冷笑話專區；完成全部挑戰題且至少答對 2 題後，才會從 `cold-joke-bank.js` 的 200 則對話、雙關與情境反差題庫中隨機解鎖 1 則冷笑話，並可查看笑點理由
- 響應式設計，支援電腦、平板與手機

## 預設餐點

在左側「一鍵載入預設餐點」區域選擇範例餐點，系統會自動勾選食物並開始模擬。套用後仍可手動勾選或取消食物，再按「把食物放入消化道」重新計算。

預設餐點是課堂示範用的組合，不代表固定或完整的實際飲食建議。

## 消化時間與未完成警告

時間軸旁的按鈕可切換兩種模式：「全程固定」讓 1× 在整段 72 小時都以每秒約 2 個模擬分鐘播放；「分段流速」則將 0～60 分鐘設定為每秒 1 個模擬分鐘，60 分鐘～72 小時設定為每秒 5 個模擬分鐘。0.5×、5× 等倍速會同步套用到兩段，畫面會同時顯示兩段的換算與目前所在區段。

食物圖示會沿著器官位置平順移動。只有時間軸到達 72 小時且食物仍未完成時，才會保留它在當下器官，維持正常不透明度，並顯示紅色三角形警告與列表紅色光圈；其他時間不會顯示這些警示。點選列表中的未完成食物時，畫面上的聚焦標記會取代食物外圈光環，列表仍保留紅色警示；已在 72 小時內完成的食物則會進入「已排出體外」。

## 挑戰題

只有按下「把食物放入消化道」或套用預設餐點後，系統才會依選取的食物種類與數量從 220 題生活情境題庫中隨機抽題。按「重新開始」會清除題目並提醒先選取食物。每次至少 3 題，最多 10 題；重新載入餐點會重新抽取。每題回答後會停用所有選項，顯示完整的正確或錯誤說明，按「下一題」才能繼續，最後會公布答對與答錯數量。題目是課堂用的簡化模型，答案與解析不代表醫療建議。

每題的三個選項會重新排列，正確答案會分散在不同位置，不會固定在第一個選項。回答完全部題目後，挑戰題下方才會解鎖整個題庫隨機抽出的食物解謎；先閱讀直接的謎面與短提示，再按「顯示解答」查看答案。觀察重點下方的冷笑話專區則需要完成全部題目，並至少答對 2 題才會解鎖；解鎖後可按「查看理由」閱讀諧音或情境比喻的笑點說明。按「重新抽題」時，挑戰題、食物解謎與冷笑話會一起重新抽取。尚未達成條件時會保留清楚的解鎖提示。

## 本機執行

直接用瀏覽器開啟 `index.html`，或使用簡易伺服器：

```bash
python3 -m http.server 8000
```

再開啟：

```text
http://localhost:8000
```

## 部署到 GitHub Pages

1. 建立新的 GitHub Repository。
2. 將本專案所有檔案上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. 在 `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/root`。
6. 儲存後等待 GitHub Pages 產生網址。

## 科學說明

本網站中的時間與消化比例為教學用簡化模型。真實人體消化速度會受到個人體質、食物份量、脂肪含量、咀嚼程度、健康狀況與其他因素影響，不應用於醫療診斷。

本網站不再為了讓所有食物在 72 小時內排出而壓縮胃部之後的時間。不同食物、份量與咀嚼程度可能造成估計時間超過時間軸；此時畫面會保留未完成狀態，方便觀察模型的限制。
